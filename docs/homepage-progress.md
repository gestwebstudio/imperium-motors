## Где что лежит

- **Вёрстка главной:** `public/ui-kit/home.html` (+ инлайн-JS каруселей),
  `public/ui-kit/home.css` (раскладка + адаптив), стили компонентов —
  `components.css`, `buttons.css`, токены (цвета/шрифты/типографика) — `tokens.css`.
- **Резиновый каркас:** всё в `rem`, корень `html { font-size: clamp(10px,0.833vw,16px) }`
  (опора — макет 1920). Между брейкпоинтами всё масштабируется само.
- **Брейкпоинты адаптива:** 1200 / 960 / 768 (перекладка: `--visible` логотипов,
  `--cols` каталогов, бенто 3→2→1, блоки в столбик, hero в колонку, шапка-бургер).
- **Картинки:** `public/home/{cars,logos,catalog,gallery,reviews,misc}/`,
  `public/brand-logos/`. Исходники (не в git-выдаче webp) — папка `images/`.

### 1. Картинки → webp из папки `images` (СДЕЛАНО)
Все фото главной пересобраны из `images/` в webp (sharp, photo q85, лого near-lossless),
разложены по `public/home/{categories,features,catalog,logos,reviews,gallery}/`.

`testimonial.png` → `/home/reviews/review1.webp`. Проверено замером: 32 картинки
грузятся, битых нет, ни одного не-webp (кроме svg-логотипа) не осталось.
Исходники `images/` оставлены вне git (по умолчанию) — при необходимости закоммитить отдельно.

### 1b. Обновление элементов кита по Figma (СДЕЛАНО)
Синхронизировано с макетом:
- **Кнопки** (`buttons.css`): исправлены высоты — S 28px (верт. пад. 5px), M 36px (8px),
  icon-only S/M (28/36). L/CTA уже совпадали. Замер подтверждает 28/36/44.
- **Card** (`components.css`): паддинг карточки 32→26px (`--card-padding` на `.car-card`,
  node 571-1785). Демо-кнопки car-card переведены на size m (как в макете).
- **Логотип-карточка** (`.brand-card`): тень `--shadow-card-brand` ближе к макету
  (blur ~50px, alpha .5, симметрична по X — чтобы не резалась в ряду); hover-scale
  1.12→1.04 по обновлённому node 201-11228 (плитка растёт слабо). Габариты/цвета
  (324.8×186.7, r22, bg stone-beige .4 / hover white .5) уже совпадали.

### 1c. Компоненты + анимации (СДЕЛАНО, коммит 3b41b43)
- **Телефон в шапке** (`.phone-btn`, node 102-18644): круг 46px, по ховеру

- **Карточки трейд-ин/лизинг** (`.promo-card`, node 58-1968 / 58-1916): hover —

### 1d. Раскладка блоков логотипов и авто (СДЕЛАНО, коммит 0805253)
По макету 141-1958: карточки на всю ширину блока (логотипы 5×340.8px,
авто 4×432px — ширина car-card из кита). Стрелки-навигация — абсолютом
поверх крайних карточек, скрыты по умолчанию, появляются по ховеру на блок.
`--cols` авто 3→4 (+шаг 4→3→2→1). Карусель (JS) не менялась — работает.

### 2. Токены под стили без точного соответствия в ките
При переводе шрифтов у части элементов **нет точного токена**: заголовок отзыва
`.review__title` (3.5rem, 400/800), `.review__name` (1.25rem/600), заголовки футера
(1.25rem/600), веса `.visit__title` (600/800). Сейчас привязаны к ближайшему токену
по значению, вес оставлен литералом. Уточнить у заказчика/по Figma — возможно завести
новые токены в `tokens.css`.
