## Scope — только 5 блоков (не весь макет)
Крошки → заголовок → сортировка → фильтры → карточки с догрузкой.

### 1. Хлебные крошки
`Breadcrumbs` (HeroUI). Путь ≈ `Главная / Каталог` (метки уточнить по Figma).

### 2. Заголовок
Заголовок страницы каталога (текст/размер — из Figma).

### 3. Сортировка
Дропдаун HeroUI. Пункты ровно три:
- по возрастанию цены
- по убыванию цены
- по популярности

### 4. Фильтры
**Блок выбранных фильтров (сверху):**
- показывается **только когда выбран хотя бы один фильтр** ниже (иначе скрыт);
- каждый выбранный фильтр — чип **тега типа Filter** (`2026 ×`, уже есть в ките); по **×** удаляется один;
- кнопка **«Сброс»** — удаляет все фильтры.

**Сами фильтры (HeroUI):**
- раскрываются **аккордеоном** (`Accordion`), внутри — выбор **чекбоксами (галочками)**;
- наборы характеристик в секциях — **рандомные, придумать самому** (марка, кузов, топливо, привод, КПП, год, цвет и т.п.);
- секции **«Цена»** и **«Мощность»** — кастомный компонент:
  - **ползунок из HeroUI** (`Slider`, двусторонний), **поля ввода над ним — кастомные**;
  - левое поле — маска начала диапазона `от 4 500 0..`, правое — `до 50 000 0..` (число видимых цифр подобрать под ширину поля);
  - **двусторонняя синхронизация:** ввод числа в поле двигает соответствующий бегунок; перетаскивание бегунка меняет число в поле; левое ↔ левый, правое ↔ правый;
  - «Мощность» — та же механика, но в **л.с.**

**Прилипание и внутренний скролл блока фильтров:**
- блок **`position: sticky`**, при скролле страницы вниз прикрепляется к верху окна;
- **`top` при прилипании = вертикальному зазору между верхом блока фильтров и заголовком над ним** (значение снять из Figma);
- если блок выше вьюпорта — **внутренний скролл**: `max-height: calc(100vh − top − нижний_зазор)` + `overflow-y: auto`.

### 5. Карточки
Карточки авто (React-порт). **Infinite scroll** — автодогрузка при скролле вниз; несколько рядов, чтобы догрузка срабатывала несколько раз.

## Важные заметки по HeroUI v3
- API отличается от v2: нет `HeroUIProvider`, `SelectItem`, `BreadcrumbItem`; compound-компоненты (Root/Trigger/Item), на react-aria.
- Внутренние части (Checkbox, Slider fill/thumb) **плохо стилизуются className** — их тема на `--accent` и своих классах с высоким приоритетом. Обход: переопределять `--accent`/классы через CSS (`catalog.css`) или делать элемент кастомным.
